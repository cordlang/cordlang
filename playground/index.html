Cordlang Playground

Compile .cord with the Cordlang CLI for now. A future build will ship a WASM compiler for in-browser codegen.

CLI workflow

cordlang compile sample.cord --ir
cordlang compile sample.cord --backend react
cordlang check sample.cord

Sample counter.cord

def Counter
  state count=0
  props label: string = "Counter"
  col gap=16 p=24 center
    h1 "#{label}" size=xl bold
    span "#{count}" size=4xl bold
    row gap=8 center
      btn "-" @click=setCount(count - 1) variant=outline
      btn "+" @click=setCount(count + 1) variant=primary
  1. Save the sample as sample.cord
  2. Run cordlang compile sample.cord --ir to inspect the IR
  3. Run with --backend react|svelte|vue|solid for codegen
