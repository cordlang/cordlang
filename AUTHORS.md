## How credit works

| File | Purpose |
|------|---------|
| **AUTHORS.md** (this file) | Who built Cordlang (humans & roles) |
| **CONTRIBUTING.md** | How to contribute (setup, tests, PR rules) |
| **Git history** | Canonical technical credit (`git shortlog -sn`) |
| **GitHub Contributors** | Auto graph on the repo page |

If you contribute and want your name here, say so in the PR description.
